# Code of Conduct

## Our standard

SAM Doctor is a small project for people debugging difficult deployment failures.
Participants are expected to be respectful, specific, and constructive. Assume
that a report is made in good faith, focus criticism on the code or evidence,
and make room for different levels of AWS and Python experience.

Unacceptable behavior includes harassment, discrimination, threats, personal
attacks, deliberate exposure of private information, and sharing credentials or
unredacted customer logs.

## Maintainer response

Maintainers will make a good-faith effort to clarify, moderate, or remove
content that violates this standard. A maintainer may close a conversation or
restrict participation when someone continues harmful behavior after a clear
request to stop.

## Reporting

For conduct concerns, contact the repository maintainer privately through the
GitHub profile rather than posting sensitive details in an issue. For security
vulnerabilities, follow [SECURITY.md](SECURITY.md). For ordinary bugs and rule
requests, use the issue forms and share only a minimal sanitized excerpt.

This code of conduct applies to issues, pull requests, discussions, reviews,
and other project spaces maintained by the SAM Doctor project.
