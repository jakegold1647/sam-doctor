# Security policy

SAM Doctor processes logs locally and is designed to avoid exposing matched
identifiers in reports. It is not a complete secret scanner.

If you find a redaction bypass, unsafe report rendering issue, or other security
problem, do not open a public issue with a proof containing real secrets. Open a
private GitHub security advisory for this repository or contact the maintainer
through the repository owner profile with a sanitized reproduction.

Do not send AWS credentials, session tokens, customer logs, or personal data.
