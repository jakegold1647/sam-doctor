# SAM Doctor founder-edition product listing

## Product name

SAM Doctor founder edition - local AWS deployment diagnostics

## One-line description

Turn SAM, CloudFormation, IAM, and GitHub Actions deployment logs into a local, evidence-first diagnostic report.

## Checkout description

SAM Doctor is a local Python tool for developers who are tired of starting AWS deployment debugging with a vague error message.

Paste or import a log. SAM Doctor matches supported failure patterns, redacts common identifiers, shows the evidence that supports each finding, suggests safe verification steps, and creates a Markdown report you can attach to a ticket or share with a teammate.

The founder edition includes expanded diagnostic rules, batch analysis, JSON and richer Markdown reports, configurable redaction, and a commercial-use license.

It does not upload logs, access an AWS account, modify infrastructure, or promise an authoritative root cause.
